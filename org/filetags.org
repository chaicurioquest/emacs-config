* Filetags Configuration for Emacs
This configuration sets up two layers of tag files:
1. `~/.emacs.d/.filetags` – General-purpose tags for PIM and file management (used globally).
2. `~/.emacs.d/.filetags-org` – Specific to Org-mode and Org-Roam files under `~/wspace/org/notes/`.
Based on Karl Voit’s tag guidelines:
- Lowercase, plural, minimal, non-overlapping, general
- Avoids redundancy
- Features:
- *Future-proof*: Tidy structure and extensible; now integrated with glossary for acronym handling.
- *Reliable*: Uses `ht` and `f.el` for parsing; mutual exclusivity preserved where needed.
- *Minimal*: Lightweight, no UI assumptions; completion via ivy or built-in.
- *Portable*: Works across laptop, Termux, tablet.
- *Synced*: Via GitHub and Syncthing.

* ACTIVE Tag Management
This section manages global and Org-specific tags using `.filetags` and `.filetags-org`.

#+BEGIN_SRC emacs-lisp
(defun my-org--filetags-path ()
  "Return path to the active .filetags file for the current device.
Checks user-emacs-directory first (symlink or real file), then
falls back to device-specific default location."
  (let ((emacs-link (expand-file-name ".filetags" user-emacs-directory)))
    (cond
     ;; Symlink in emacs.d -> resolve to real file
     ((file-symlink-p emacs-link) (file-truename emacs-link))
     ;; Real file already in emacs.d
     ((file-exists-p emacs-link) emacs-link)
     ;; Device-specific fallback locations
     ((eq my-device 'laptop)  (expand-file-name "~/.filetags"))
     ((eq my-device 'tablet)  (expand-file-name ".filetags" my/notes-root-dir))
     ((eq my-device 'phone)   (expand-file-name "storage/shared/.filetags"
                                                 (getenv "HOME")))
     (t (expand-file-name "~/.filetags")))))
#+END_SRC

#+BEGIN_SRC emacs-lisp
(defun my-org-read-filetags ()
  "Read and return a list of tags from both global and extra .filetags files.
Per Karl Voit's guidelines, multiple tags per line are mutually exclusive,
but parsed here as individual tags for flat completion."
  (let ((files (cons (my-org--filetags-path)
                     filetags-extra-tag-files))
        (tags '()))
    (dolist (file files)
      (when (file-exists-p file)
        (with-temp-buffer
          (insert-file-contents file)
          (goto-char (point-min))
          (while (not (eobp))
            (let* ((line  (buffer-substring-no-properties
                           (line-beginning-position)
                           (line-end-position)))
                   (clean (car (split-string line "#")))
                   (words (split-string (string-trim clean) "\\s-+" t)))
              (dolist (tag words)
                (push tag tags)))
            (forward-line 1)))))
    (delete-dups (nreverse tags))))
#+END_SRC

#+BEGIN_SRC emacs-lisp
(defun my-org-set-filetags ()
  "Interactively assign tags from .filetags to the current Org heading.
Uses completing-read-multiple (Vertico/orderless aware)."
  (interactive)
  (require 'org)
  (let* ((all-tags      (my-org-read-filetags))
         (current-tags  (org-get-tags nil t))
         (selected-tags (completing-read-multiple
                         "Select tags: "
                         all-tags nil nil
                         (mapconcat #'identity current-tags ","))))
    (org-set-tags selected-tags)))
#+END_SRC

#+BEGIN_SRC emacs-lisp
(global-set-key (kbd "C-c f t") #'my-org-set-filetags)
#+END_SRC
